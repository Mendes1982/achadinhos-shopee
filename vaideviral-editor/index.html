Como funciona:

Navegadores impedem que scripts de web scraping acessem perfis de forma direta devido a CORS. Para baixar o canal de forma limpa e automática, utilize o script local baixar.py disponível na pasta do seu projeto.

python baixar.py -u "" -c 10

Instruções Passo a Passo:

  1. Abra seu Terminal ou PowerShell.
  2. Navegue até a pasta do projeto: cd D:\Users\Documents\TRAMPOS\vaideviral-editor
  3. Copie o comando acima e cole no terminal para rodar o download em lote.
  4. Os vídeos serão baixados na pasta videos_baixados.
  5. Depois de baixar, arraste-os para o editor para editá-los em lote!
